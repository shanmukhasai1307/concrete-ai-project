# 🏗️ Concrete AI Intelligence Platform

An AI-powered web application that recommends optimized concrete mix parameters based on project requirements. The platform analyzes project details such as building type, land area, number of floors, environmental conditions, and target concrete strength to generate intelligent recommendations.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/shanmukhasai1307/concrete-ai-project.git
```

```bash
cd concrete-ai-project
```

---

## Backend Setup

```bash
cd backend
```

Create Virtual Environment

```bash
python -m venv .venv
```

Activate Virtual Environment (Windows)

```bash
.venv\Scripts\activate
```

Install Dependencies

```bash
pip install -r requirements.txt
```

Run Backend

```bash
uvicorn main:app --reload
```

Backend URL

```
http://127.0.0.1:8000
```

---

## Frontend Setup

```bash
cd frontend
```

Install Dependencies

```bash
npm install
```

Run React Application

```bash
npm start
```

Frontend URL

```
http://localhost:3000
```

The trained model predicts optimized concrete recommendations for sustainable and efficient construction.
